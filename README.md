# Sales Analysis Dashboard using Excel

## Project Overview

This project provides a complete sales analysis solution using Microsoft Excel. The objective was to clean, transform, model, and analyze sales data from multiple sources and build an interactive dashboard for business decision-making.

## Tools Used

* Microsoft Excel
* Power Query
* Power Pivot
* DAX
* Pivot Tables
* Pivot Charts

## Dataset

The project includes data from multiple business entities:

* Customers
* Products
* Sales
* Payment Methods
* Brands
* Branches

## Data Preparation

Using Power Query:

* Merged sales data from 2023 and 2024
* Removed duplicates
* Handled missing values
* Standardized date formats
* Split and transformed columns
* Created conditional classifications for invoices

## Data Modeling

Relationships were created using Power Pivot:

* Customers ↔ Sales
* Products ↔ Sales
* Payment Methods ↔ Sales
* Brands ↔ Products
* Branches ↔ Sales

## DAX Measures

Created key business metrics:

* Total Sales
* Active Customers

## Analysis Performed

* Sales by Brand
* Sales by Category
* Monthly Sales Trend
* Sales by Branch
* Payment Method Distribution

## Dashboard Components

* Bar Chart (Sales by Branch)
* Line Chart (Monthly Sales Trend)
* Pie Chart (Sales by Payment Method)
* Stacked Column Chart (Category vs Brand Sales)
* KPI Cards

## Business Value

The dashboard enables stakeholders to monitor sales performance, compare branch performance, analyze customer activity, and identify sales trends efficiently.
